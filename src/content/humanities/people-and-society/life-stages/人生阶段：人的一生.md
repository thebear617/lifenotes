### 年龄



| 年龄 | 古称 | 说明 |
|------|------|------|
| 出生 | 初度 | 屈原《离骚》"皇览揆余初度兮" |
| 未满周岁 | 襁褓 | 婴儿包裹时期 |
| 2-3 岁 | 孩提 | 两三岁会笑、可提抱 |
| 3-8 岁 | 垂髫 | 儿童头发下垂 |
| 7-8 岁 | 始龀 | 换牙时期 |
| 8-14 岁 | 总角 | 束发两结如角 |
| 10 岁 | 幼学 | 《礼记》"人生十年曰幼学" |
| 13 岁 | 舞勺 | 男子学乐舞勺 |
| 15 岁 | 束发 / 志学 / 及笄 | 男束发；"十五而志于学"；女及笄 |
| 16 岁 | 破瓜 | 女子，瓜字拆为二八 |
| 20 岁 | 弱冠 | 《礼记》"二十曰弱冠"，男子加冠 |
| 24 岁 | 花信 | 女子花信年华 |
| 30 岁 | 而立 | "三十而立" |
| 40 岁 | 不惑 | "四十而不惑" |
| 50 岁 | 知天命 / 艾 | "五十而知天命"；《礼记》"五十曰艾" |
| 60 岁 | 花甲 / 耳顺 | 干支六十年一轮回；"六十而耳顺" |
| 70 岁 | 古稀 / 从心 | 杜甫"人生七十古来稀"；"七十而从心所欲" |
| 80 岁 | 耄 / 杖朝 | 八十曰耄；《礼记》"八十杖于朝" |
| 80-90 岁 | 耄耋 | 耄指 80-90 岁，耋指 70-80 岁，耄耋泛指八九十岁高龄，最常用 |
| 90 岁 | 鲐背 | 90 岁专属古称。老人皮肤上生出老年斑，像鲐鱼的斑纹，故称鲐背之年 |
| 100 岁 | 期颐 | 100 岁，注意不要和 90 岁混淆 |

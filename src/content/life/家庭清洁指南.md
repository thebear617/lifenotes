## 一、衣物去渍

不同污渍的处理思路不同，核心原则是**先吸附后清洗，先测试后处理**。

| 污渍 | 处理 | 关键注意 |
|---|---|---|
| 血渍 | 冷水 + 肥皂类清洁剂搓洗 | 不要先用热水，蛋白质遇热会凝固 |
| 火锅油渍 | 盐 + 洗洁精 + 温水涂上，等待后再搓 | 先搓可能使油渍扩散 |
| 霉斑 | 根据面料选择清洁剂并先做局部测试 | 不要把醋、含氯清洁剂等随意混合 |
| 咖啡渍 | 尽快用清水处理，再按面料清洗 | 久置后更难处理 |
| 汗渍 | 及时清洗，必要时使用适合面料的去渍剂 | 长时间放置可能变黄 |
| 圆珠笔油 | 酒精局部点涂后清洗 | 先试不显眼处，远离明火 |
| 不确定污渍 | 先查看洗涤标签并做局部测试 | 贵重面料交给专业清洗 |

## 二、锅具清洁

核心思路是「酸（白醋/陈醋）+ 碱（小苏打）+ 表面活性剂（洗洁精）」组合，配合物理摩擦或静置渗透。

| 问题 | 配方 | 步骤 | 原理 |
|---|---|---|---|
| 锅底厚油垢 | 食盐 + 小苏打 + 洗洁精 + 陈醋 + 温水 | 泡 15min → 钢丝球刷 → 抹布擦 | 酸碱反应 + 表面活性剂 + 摩擦 |
| 锅底油垢 | 小苏打 + 食盐 + 厚纸巾 + 白醋 | 铺纸巾+倒白醋 → 静置 30min → 清洗 | 纸巾吸附 + 酸碱反应 |
| 锅底稍糊 | 洗洁精 + 清水 + 烘干纸 | 静置 1h → 倒污水 → 纸擦残渣 → 冲洗 | 烘干纸吸附 + 表面活性剂 |
| 铁锅生锈粘锅 | 洗洁精 + 白醋 + 钢丝球 + 食用油 | 钢丝球去锈 → 小火烧干 → 抹油 → 静置一晚 | 酸除锈 + 油膜防锈防粘 |

- 钢丝球会刮伤不粘锅涂层，仅适用于铁锅或不锈钢锅。
- "烘干纸"指衣物柔顺纸/烘干机用纸，非厨房纸。

## 三、生活妙用

可乐的核心成分是碳酸、磷酸、糖和香料，其弱酸性可能对部分水垢或污渍产生作用，但不能当作通用清洁剂。

| 用法 | 配方 | 适用 | 风险 |
|---|---|---|---|
| 清洁马桶 | 可乐 + 洗衣粉 | 马桶黄斑（尿碱） | 先小范围测试 |
| 擦玻璃 | 可乐 + 白醋 | 浴室玻璃镜子 | 通风；不用于防雾镀膜玻璃 |
| 灶台油污 | 可乐 + 洗洁精 | 灶台油污 | 清洁后充分擦净 |
| 水龙头水垢 | 可乐 + 洗衣液 | 水龙头水垢 | 注意材质兼容性 |
| 去口香糖 | 可乐 + 酒精 | 衣物/地面粘的口香糖 | 酒精挥发，远离明火 |

> 以上方法多为经验性妙招，效果因污渍和材质而异；不要混合未知清洁剂，也不要用于食品接触表面后不清洗。

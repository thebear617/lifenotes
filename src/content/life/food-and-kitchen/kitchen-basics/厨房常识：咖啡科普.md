## 常见咖啡品类

![常见咖啡品类与配方对照图](/images/coffee-guide/coffee-types.jpg)

| 咖啡品类 | 常见配方 |
| --- | --- |
| 浓缩咖啡 Espresso | 浓缩咖啡液 |
| 美式咖啡 Americano | 水、浓缩咖啡液 |
| 拿铁咖啡 Latte | 奶泡、牛奶、浓缩咖啡液 |
| 摩卡咖啡 Mocha | 奶泡、牛奶、浓缩咖啡液、巧克力酱 |
| 卡布奇诺 Cappuccino | 厚奶泡、牛奶、浓缩咖啡液 |
| 生椰拿铁 Coconut Latte | 生椰乳、浓缩咖啡液 |
| 澳白 Flat White | 薄奶泡、牛奶、浓缩咖啡液 |
| 脏咖啡 Dirty | 浓缩咖啡液、牛奶或冰博客 |
| 阿芙佳朵 Affogato | 冰淇淋、浓缩咖啡液 |

以上是常见的基础配方，实际配方会因咖啡店、杯型和制作方式而异。

## 2026-09-07 ——分类树重构、内容大幅删减合并

>  一是进行内容上的删减和合并，删减了很多过度展开的转录内容和网上一下就能搜到的信息，二是重构了分类树和领域————认为之前的分类树过于冗余重构依据官方给出的[^经济行业分类]，以及我觉得可以分为跟社会相关程度高的（人文与自然、服务业、工业）和与社会相关程度低，自我属性比较强的（生活与美食、随笔），进一步可以把前者根据与钱的相关程度拆分为人文自然与服务业、工业

[^经济行业分类]:
  >统计局《三次产业划分规定》：三次产业 → 门类 → 大类 → 中类 → 小类
  
  - 第一产业 = A 农林牧渔
  - 第二产业 = B 采矿 + C 制造 + D 电力燃气水 + E 建筑
  - **第三产业（= 服务业）= F 到 T 共 15 个门类**
  
  **服务业 = 第三产业 = 15 个门类**
  
  | 门类 | 名称 |
  |---|---|
  | F | 批发和零售业 |
  | G | 交通运输、仓储和邮政业 |
  | H | 住宿和餐饮业 |
  | I | 信息传输、软件和信息技术服务业 |
  | J | 金融业 |
  | K | 房地产业 |
  | L | 租赁和商务服务业 |
  | M | 科学研究和技术服务业 |
  | N | 水利、环境和公共设施管理业 |
  | O | 居民服务、修理和其他服务业 |
  | P | 教育 |
  | Q | 卫生和社会工作 |
  | R | 文化、体育和娱乐业 |
  | S | 公共管理、社会保障和社会组织 |
  | T | 国际组织 |
  
  **eg:酒店的位置**
  
  ```
  第三产业（服务业）
  └── 门类 H：住宿和餐饮业
      └── 大类 61：住宿业
          └── 中类：
              611 旅游饭店（星级/品牌酒店主要落这）
              612 一般旅馆

              614 露营地服务

  ```
